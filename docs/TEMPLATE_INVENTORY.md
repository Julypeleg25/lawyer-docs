- Main document contains paragraphs and numbering; no headers, footers, or media parts were found.
- 15 syntactically matched placeholders were found across Word runs.
- Supported optional instruction: `Xתיאור חוב – לא חובה (להוסיף את המילה למעט)X`.
- The buyer line contains an unbalanced `X` sequence around the first name, last name and ID fields. The scanner deliberately marks the template invalid rather than guessing boundaries.
- No explicit buyer/seller repeat boundaries exist. To support multiple parties, add the documented `X#קוניםX` / `X/קוניםX` and `X#מוכריםX` / `X/מוכריםX` marker paragraphs.
- Several newly discovered labels require classification in the fields management screen before the template becomes usable.

The original binary is version-controlled in `templates/`. This report records observations only and does not alter legal text.
