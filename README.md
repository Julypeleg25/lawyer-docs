# מערכת הפקת מסמכים משפטיים

יישום React ו-Node.js להפקת מסמכי DOCX בעברית מתבניות הנשמרות ב-Git. נתוני לקוחות,
נכסים והגדרות שדות נשמרים ב-MongoDB; ערכי עסקה וקבצים מופקים אינם נשמרים.

## הפעלה מקומית

1. העתיקו את `.env.example` לקובץ `.env` ועדכנו לפי הצורך.
2. הפעילו `docker compose up -d` להפעלת MongoDB.
3. הפעילו `npm install`, ולאחר מכן `npm run dev`.
4. פתחו `http://localhost:5173`.

התבניות נמצאות בתיקיית `templates` והן חלק מהמאגר הפרטי. אין לשים שם סודות.

## סימוני תבנית

- שדה רגיל: `Xיום החתימהX`
- שדה אופציונלי: `Xתיאור חוב – לא חובה (להוסיף את המילה למעט)X`
- אזור קונים חוזר: `X#קוניםX` ... `X/קוניםX`
- אזור מוכרים חוזר: `X#מוכריםX` ... `X/מוכריםX`

ראו את לשונית **מדריך** ביישום למידע מלא.
